# Provenance

Files in this directory were downloaded unmodified on 2026-08-21 from the
LibreOffice dictionaries collection, directory `is/`:

https://github.com/LibreOffice/dictionaries/tree/master/is

| File | Origin |
|---|---|
| `hyph_is.dic` | Icelandic hyphenation patterns (málföng.is, CC BY 4.0) in libhyphen format |
| `is.aff`, `is.dic` | Hunspell-is spelling dictionary (github.com/nifgraup/hunspell-is) |
| `license.txt` | Upstream license/attribution text |
| `description.xml`, `dictionaries.xcu` | LibreOffice extension metadata (reference only, not installed) |

`../dictionaries/is_IS/` contains the same files renamed to InDesign's
conventions (`hyph_is_IS.dic`, `is_IS.aff`, `is_IS.dic`) plus generated
description stubs (`desc_*.txt`) and `README_is_IS.txt` (a copy of
`license.txt`).

To refresh from upstream: re-download the files above, re-apply the renames,
and re-run the installer.
