Íslensk orð­skipting fyrir InDesign.

Rétt orðskipting og stafsetningarleiðrétting á íslensku í Adobe InDesign — sett upp með einni skipun.

Uppsetning — límdu í Terminal
$ curl -fsSL https://raw.githubusercontent.com/arnorb/hunspell-is-indesign/main/install.sh | sudo bash

Virkar með InDesign 2024, 2025 og 2026. Fjarlæging: sama skipun með -s -- --uninstall aftast.

1

Lokaðu InDesign

Opnaðu svo Terminal: Cmd+bilslá, skrifaðu „Terminal", Enter.

2

Límdu skipunina

Ýttu á Enter og sláðu inn lykilorðið þitt þegar beðið er um það.

3

Endurræstu InDesign

Stilltu tungumál textans á Icelandic og kveiktu á Hyphenate.

Allt annað — notkun, fjarlæging, hvernig þetta virkar — er í README á GitHub.

Free Icelandic hyphenation & spelling for Adobe InDesign, using the official Árni Magnússon Institute patterns (CC BY 4.0). Docs in English in the README. Not affiliated with Adobe.
